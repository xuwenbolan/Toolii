# Monetization Model

Status: draft | Updated: 2026-03-03

---

## Phase 1: MVP Validation (Month 1-2)

- All features free
- ID photo processing shows tip QR code (WeChat / Alipay) after completion
- Suggested tip: ¥5-10 (~£0.5-1)
- Goal: validate demand, collect user feedback

---

## Phase 2: Card Code Paid Model (Month 3+)

### Free Features

- Image compress, format convert, HEIC convert
- PDF merge, compress
- ID photo processing (watermarked preview)

### Paid Features (via card code credits)

- ID photo watermark-free HD download (1 Credit)
- ID photo layout export for printing (1 Credit)
- Batch processing (1 Credit per batch)

### Pricing

- Single card: ¥8 / 1 credit (not recommended, steer to double)
- Double card: ¥10 / 2 credits (primary product, ¥5/credit)
- Five-pack: ¥20 / 5 credits (future, ¥4/credit)

### Payment Methods

- Auto card-selling platform (primary) — user pays, auto-receives card code
- WeChat / Alipay manual distribution (auxiliary) — small amount or special cases
- Payment API direct top-up (reserved) — future WeChat Pay / Alipay / Stripe integration

### Social Growth Mechanism

- Users can share unused credits to friends
- Friends experience product, then purchase card codes themselves
- More natural than traditional invite-code referral, higher conversion rate

## Phase 2 (Alternative): High-ARPU Service Model

Alternative to low-price volume model. Core idea: **Low-frequency scenarios don't need volume; they need higher unit price. Bundle tools into services, sell convenience not features.**

### Service Packages

| Package | Price | Contents | Target |
|---------|-------|----------|--------|
| Visa materials full-service | ¥88 | Checklist + ID photo + doc processing + smart check + itinerary/cover letter + packaging + 30-day storage | Schengen/US visa applications |
| ID photo + print layout | ¥15-20 | ID photo processing + multi-spec output + Boots 6x4 layout | Photo-only users |

### Competitive Comparison

| Option | Price | User Gets |
|--------|-------|-----------|
| Visa agency full service | ¥500-2,000 | Full processing, expensive |
| **Toolii visa full-service** | **¥88** | Checklist + photo + docs + check + itinerary + storage, 1/6~1/20 of agency price |
| Boots one photo session | £9-12 (~¥80-100) | Just the photo, handle everything else yourself |
| **Toolii ID photo + layout** | **¥15-20** | Photo + print layout, 1/5 of Boots |

Note: High-ARPU model and card code model are not mutually exclusive. Keep single-use card code option while using service packages as primary upsell.

---

## Phase 3: Scale (Once User Base Grows)

- Integrate direct payment top-up (WeChat Pay / Alipay / Stripe)
- Google AdSense ads (tool sites have higher CPM)
- Partnership with Boots/Snappy Snaps for printing referrals
- Monthly/annual membership (unlimited paid features)
- Expand card code denominations and bundles
